# 📊 Social Media Engagement Analytics Using Python

## 📌 Project Overview
This project analyzes 5,000 social media records using Python to understand content performance, audience behaviour, engagement patterns, and sentiment trends. It involves data cleaning, exploratory data analysis, statistical analysis, and visualization.

## 🎯 Objectives
- Clean and preprocess social media data.
- Handle missing values, duplicates, and inconsistent data.
- Perform data analysis using Pandas and NumPy.
- Calculate engagement metrics and descriptive statistics.
- Identify patterns across post types, categories, countries, and sentiments.
- Visualize findings using different Python libraries.

## 🛠️ Tools & Technologies
**Python | Pandas | NumPy | Matplotlib | Seaborn | Plotly | Jupyter Notebook**

## 🔍 Project Workflow

1. **Data Import & Setup:** Imported the CSV, checked data types, converted date columns, and performed NumPy operations.
2. **Data Cleaning:** Handled missing values, duplicates, incorrect data types, inconsistent categories, unrealistic values, and sentiment labels. Extracted hashtag counts.
3. **Exploratory Data Analysis:** Examined dataset structure, summary statistics, categorical distributions, correlations, and grouped metrics.
4. **Data Wrangling:** Created `engagement_score` and `hashtag_count` and performed groupby analysis.
5. **Statistical Analysis:** Calculated mean, median, mode, standard deviation, variance, and percentiles.
6. **Data Visualization:** Created visualizations using Matplotlib, Seaborn, and interactive Plotly charts.

## 📈 Key Findings

- **Content Performance:** Video posts recorded the highest average engagement rate. Food was the best-performing category, while Brazil had the highest average engagement rate.
- **User Trends:** Users aged 24 had the highest average engagement rate. Verified accounts had a higher engagement rate, while non-verified accounts had a higher engagement score.
- **Behavioural Insights:** Mobile users recorded the highest average watch time. The best posting time could not be identified because actual posting times were unavailable.
- **Sentiment Analysis:** Negative posts recorded the highest average engagement score and engagement rate.
